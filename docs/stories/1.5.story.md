# Story 1.5: Combat System Extraction & Enhancement

<!-- Context: Brownfield enhancement - formalizing existing main.ts combat into modular system with new features -->

## Status
Draft

## Story
**As a** player,
**I want** richer combat with defend and flee options and visible monster health,
**so that** combat encounters feel tactical rather than just bumping into enemies.

## Acceptance Criteria
1. Combat logic is extracted from main.ts into a dedicated Combat module
2. Player can choose to defend (reduced incoming damage) instead of attacking
3. Player can attempt to flee combat (move away from monster on their turn)
4. Monster health bars or HP indicators are visible during combat
5. Combat message log shows detailed results (damage dealt, blocked, fled, etc.)
6. Monster death drops a type-specific reagent item in addition to teeth
7. Existing bump-to-attack, damage calculation, and death handling continue to work unchanged

## Dev Notes

### Existing Implementation (Brownfield Context)
The current `main.ts` contains inline `combat()` function:
- Bump-to-attack: moving into a monster triggers combat
- Hero attacks first: `Math.max(1, heroAtk - monster.defense + random(0-4))`
- Monster retaliates: `Math.max(1, monster.attack - heroDef + random(0-2))`
- Monster death: splice from array, drop 1-5 teeth, victory check
- Hero death: `applyDamage()`, isAlive check, game over message
- Uses `getEffectiveAttack(hero)` and `getEffectiveDefense(hero)` from Hero.ts

**What exists and must NOT be broken:**
- Bump-to-attack mechanic (moving into monster = combat)
- Damage calculation using hero/monster stats
- Monster removal on death
- Teeth drops on monster kill
- Hero death detection and game over flow
- Victory condition (all monsters killed)
- Combat messages in `state.messages`

**What this story adds:**
- Combat module extraction
- Defend and flee actions (combat becomes multi-option instead of auto-resolve)
- Monster HP display during combat
- Reagent item drops

### Combat Mode Design
The current system auto-resolves combat on bump. This story introduces a combat mode where:
1. Hero bumps monster → enters combat mode (no movement allowed)
2. Combat prompt appears: `[A]ttack  [D]efend  [F]lee`
3. Hero chooses action → action resolves → monster acts → loop until combat ends
4. Combat ends when: monster dies, hero dies, or hero successfully flees

```typescript

```

### Reagent Item Model
Reagents are simple inventory items that will be consumed in Story 1.6:
```typescript

  type: 'reagent';
  monsterType: string; // links to MONSTER_DEFINITIONS type
  statBonus: { stat: string; amount: number };
}
```
