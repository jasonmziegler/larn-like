# Story 1.5: Turn-Based Combat System

## Status
Draft

## Story
**As a** player,
**I want** to engage in turn-based combat with dungeon monsters,
**so that** I can experience classic roguelike tactical combat with clear feedback.

## Acceptance Criteria
1. Approaching monsters triggers turn-based combat mode with clear visual indication
2. Combat alternates between player and monster turns with appropriate timing
3. Damage calculations use hero and monster stats with results clearly displayed
4. HP reduction shows immediate visual feedback for both player and monsters
5. Monster death removes monster from dungeon and provides basic loot (monster reagent)
6. Player death displays appropriate death message and ends current game session
7. Combat log or message area shows attack results, damage dealt, and other combat events

### Combat System Architecture
[Source: architecture/frontend-architecture.md]
**Combat.ts Component (`apps/web/src/game/Combat.ts`):**
- **Responsibility**: Turn-based combat logic and damage calculations
- **Features**: Combat state management, damage calculations, turn processing
- **Dependencies**: Hero.ts, Monster.ts, Equipment.ts for stat calculations

**Combat Integration Pattern:**
```typescript
// Expected combat system integration
class Combat {
  processAttack(attacker: Hero | Monster, defender: Hero | Monster): CombatResult {
    const damage = this.calculateDamage(attacker, defender);
    defender.currentStats.hp -= damage;
    return { damage, isKilled: defender.currentStats.hp <= 0 };
  }
}
```

### Hero and Monster Stats for Combat
[Source: architecture/data-models.md]
**Hero Stats (Combat Relevant):**
```typescript
interface HeroStats {
  hp: number;
  maxHp: number;
  strength: number;        // Affects attack damage
  dexterity: number;       // Affects hit chance/defense
  constitution: number;    // Affects HP and damage resistance
}
```

**Monster Stats (Combat Relevant):**
```typescript
interface MonsterStats {
  hp: number;
  maxHp: number;
  attack: number;          // Base attack damage
  defense: number;         // Damage reduction
}
```

**Damage Calculation Logic:**
- Hero attack damage: Base weapon damage + strength modifier + equipment bonuses
- Monster attack damage: Base attack stat + evolution bonuses
- Defense reduction: Constitution/defense stats reduce incoming damage
- Critical hits and special mechanics (future expansion)

### Death Event Processing Workflow
[Source: architecture/core-workflows.md]
**Hero Death Workflow:**
1. **Combat Resolution**: Hero HP reaches 0 from monster attack

**Monster Death Processing:**

### Turn-Based Combat Timing
**Combat Flow:**
1. **Player Turn**: Player chooses action (attack/defend/flee)
2. **Player Action Resolution**: Process player action and apply results
3. **Monster Turn**: Monster AI chooses action (typically attack)
4. **Monster Action Resolution**: Process monster action and apply results
5. **Turn End**: Check for death conditions, update display, repeat

**Timing Requirements:**
- No animation delays (AC: immediate visual response)
- Clear turn indication for player understanding
- Appropriate pacing for tactical decision making

### Input Handling for Combat
**Combat Controls:**
- **Attack**: Spacebar or Enter key (primary combat action)
- **Defend**: D key (defensive stance for damage reduction)
- **Flee**: F key or Escape (attempt to exit combat)
- **Movement**: Disabled during combat mode

### Performance Requirements
**Combat Performance:**
- Instant damage calculation and display
- Smooth turn transitions without lag
- Efficient monster removal and loot generation
- Real-time HP updates and visual feedback
