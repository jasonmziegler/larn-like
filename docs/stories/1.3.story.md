# Story 1.3: Basic Hero Creation & Stats

## Status
Draft

## Story
**As a** player starting a new game,
**I want** to create a hero with base stats and starting equipment,
**so that** I can begin exploring the dungeon with consistent starting conditions.

## Acceptance Criteria
1. Hero spawns with predetermined base stats (HP, Strength, Dexterity, Constitution, etc.)
2. Starting equipment includes basic dagger and shirt automatically equipped
3. Hero displays as ASCII character (@) on game screen with proper positioning
4. Stats are clearly visible in UI sidebar or panel during gameplay
5. Equipment slots properly display currently equipped items (weapon, armor)
6. Hero creation process completes in under 1 second

### Hero Data Model and Stats
[Source: architecture/data-models.md]
**Hero Interface:**
```typescript
interface Hero {
  id: string;
  playerId: string;
  name: string;
  level: number;
  baseStats: HeroStats;
  currentStats: HeroStats;
  equipment: EquipmentSlots;
  inventory: InventoryItem[];
  currentLocation: LocationData;
  teethCurrency: number;
  createdAt: Date;
  isAlive: boolean;
}

interface HeroStats {
  hp: number;
  maxHp: number;
  strength: number;
  dexterity: number;
  constitution: number;
}
```

**Base Stats Configuration:**
- **HP**: 30 (base and max HP for new heroes)
- **Strength**: 10 (base strength for all new heroes)
- **Dexterity**: 10 (base dexterity for all new heroes)
- **Constitution**: 10 (base constitution for all new heroes)

**Current Stats Management:**
- Support decimal values (DECIMAL(3,1)) for +0.1 reagent bonuses
- currentStats modified by reagents and leveling
- Stats reset only on hero death

### Equipment System Architecture

```typescript
interface EquipmentSlots {

  gloves: EquipmentItem | null;
  boots: EquipmentItem | null;
  ring1: EquipmentItem | null;
  ring2: EquipmentItem | null;
  amulet: EquipmentItem | null;
  belt: EquipmentItem | null; // Note: 10 slots total including belt
}
```

**Starting Equipment Requirements:**
- **Basic Dagger**: weapon slot, provides basic attack bonus
- **Shirt**: bodyArmor slot, provides basic defense bonus
- Equipment automatically assigned during hero creation
- Equipment naming includes original owner (hero name)

**Integration Pattern:**

- API call creates hero with predetermined stats and starting equipment
- Response includes fully equipped hero ready for gameplay

### Database Integration
[Source: architecture/database-schema.md]
**Heroes Table Structure:**
```sql
CREATE TABLE heroes (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    player_id UUID NOT NULL REFERENCES players(id),
    name VARCHAR(12) NOT NULL,
    level INTEGER DEFAULT 1,
    base_hp INTEGER DEFAULT 30,
    base_strength INTEGER DEFAULT 10,
    base_dexterity INTEGER DEFAULT 10,
    base_constitution INTEGER DEFAULT 10,
    current_hp INTEGER DEFAULT 30,
    current_strength DECIMAL(3,1) DEFAULT 10.0,
    current_dexterity DECIMAL(3,1) DEFAULT 10.0,
    current_constitution DECIMAL(3,1) DEFAULT 10.0,
    is_alive BOOLEAN DEFAULT TRUE
);
```
