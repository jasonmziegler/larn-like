# Story 3.5: Enhanced Inventory Management

## Status
Draft

## Story
**As a** player,
**I want** comprehensive inventory management with equipment comparison,
**so that** I can make informed decisions about gear upgrades and optimal loadouts.

## Acceptance Criteria
1. Inventory interface displays all carried items organized by type or slot compatibility
2. Equipment comparison tooltips show stat differences when hovering over potential upgrades
3. Inventory sorting options (by type, value, stats) for efficient gear organization
4. Quick-equip functionality for rapid gear swapping during dungeon exploration
5. Inventory weight or slot limits prevent unlimited item hoarding while allowing reasonable storage
6. Clear visual indicators distinguish between equipped, carried, and merchant/chest items

## Background / Rationale

The current inventory system (Story 1.2) provides basic item storage, but lacks organization, comparison tools, and capacity limits. As Epic 3 introduces merchant purchases (Story 3.2), random chest loot (Story 3.3), and monster equipment overflow (Story 3.4), players will accumulate diverse items and need better tools to manage them.

This story enhances inventory UX to support strategic equipment decisions:
- **Comparison:** See stat differences before equipping
- **Organization:** Sort items to find gear quickly
- **Capacity:** Prevent unlimited hoarding while allowing exploration
- **Efficiency:** Quick-equip for combat readiness

### Inventory Sorting Implementation

```typescript
type SortMode = 'type' | 'value' | 'slot';

function sortInventory(items: EquipmentItem[], mode: SortMode): EquipmentItem[] {
  switch (mode) {
    case 'type':
      // Group: weapons → armor → accessories
      return items.sort((a, b) => {
        const typeOrder = { weapon: 0, offHand: 0, helmet: 1, bodyArmor: 1, gloves: 1, boots: 1, ring1: 2, ring2: 2, amulet: 2, belt: 2 };
        return typeOrder[a.slot] - typeOrder[b.slot];
      });

    case 'value':
      // Sort by total stat bonuses (highest first)
      return items.sort((a, b) => {
        const aValue = a.attackBonus + a.defenseBonus;
        const bValue = b.attackBonus + b.defenseBonus;
        return bValue - aValue;
      });

    case 'slot':
      // Alphabetical by slot name
      return items.sort((a, b) => a.slot.localeCompare(b.slot));

    default:
      return items;
  }
}
```

### Equipment Comparison Tooltip Format

```typescript
function generateComparisonTooltip(
  newItem: EquipmentItem,
  currentItem: EquipmentItem | null
): string {
  const lines: string[] = [];
  lines.push(newItem.name);
  lines.push(`  ATK: +${newItem.attackBonus} | DEF: +${newItem.defenseBonus}`);
  lines.push('─────────────────');

  if (currentItem === null) {
    lines.push('Current: [Empty]');
    lines.push(`Change: +${newItem.attackBonus} ATK, +${newItem.defenseBonus} DEF`);
  } else {
    lines.push(`Current: ${currentItem.name}`);
    lines.push(`  ATK: +${currentItem.attackBonus} | DEF: +${currentItem.defenseBonus}`);

    const atkDiff = newItem.attackBonus - currentItem.attackBonus;
    const defDiff = newItem.defenseBonus - currentItem.defenseBonus;

    const atkChange = atkDiff > 0 ? `+${atkDiff}` : `${atkDiff}`;
    const defChange = defDiff > 0 ? `+${defDiff}` : `${defDiff}`;

    lines.push(`Change: ${atkChange} ATK, ${defChange} DEF`);
  }

  return lines.join('\n');
}
```

### Quick-Equip Logic

```typescript
function quickEquip(hero: Hero, inventoryIndex: number): { success: boolean; message: string } {
  const item = hero.inventory[inventoryIndex];
  if (!item) return { success: false, message: 'Invalid item index' };

  const slotKey = item.slot as keyof EquipmentSlots;
  const currentItem = hero.equipment[slotKey];

  // Swap: unequip current → equip new
  hero.equipment[slotKey] = item;
  hero.inventory.splice(inventoryIndex, 1);

  if (currentItem !== null) {
    hero.inventory.push(currentItem);
  }

  recalculateStats(hero); // Update stats immediately

  return {
    success: true,
    message: `Equipped ${item.name} (+${item.attackBonus} ATK, +${item.defenseBonus} DEF)`
  };
}
```

### Item Drop System

```typescript
interface DroppedItem {
  id: string;
  pos: { x: number; y: number };
  item: EquipmentItem;
  char: string; // Display character (e.g., '/')
  color: string; // Display color
}

function dropItem(hero: Hero, inventoryIndex: number, level: DungeonLevel): DroppedItem {
  const item = hero.inventory[inventoryIndex];
  hero.inventory.splice(inventoryIndex, 1);

  const droppedItem: DroppedItem = {
    id: `dropped_${Date.now()}_${Math.random().toString(36).substring(2, 9)}`,
    pos: { x: hero.position.x, y: hero.position.y },
    item,
    char: '/',
    color: '#FFAA00',
  };

  level.droppedItems = level.droppedItems || [];
  level.droppedItems.push(droppedItem);

  return droppedItem;
}
```

### Capacity Management Strategy

**Design Decision:**
- **Limit:** 20 items (prevents hoarding, forces strategic choices)
- **Overflow:** Player must drop or equip items before picking up new ones
- **Balance:** 20 slots allows carrying ~2 full equipment sets + some extras

**User Flow:**
1. Inventory reaches 20/20
2. Player finds valuable item in chest
3. Message: `"Inventory is full. Drop an item first."`
4. Player opens inventory, drops least valuable item
5. Player picks up new item
