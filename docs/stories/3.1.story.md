# Story 3.1: Comprehensive Equipment Slot System

## Status
Approved

## Story
**As a** player,
**I want** a structured equipment system with 10 defined slots,
**so that** I can strategically equip gear while understanding exactly what items can be worn simultaneously.

## Acceptance Criteria
1. Equipment slots implemented: 1 weapon OR 1 off-hand + 1 weapon OR 1 two-handed weapon, helmet, body armor, gloves, boots, 2x rings, 1 amulet, belt
2. Equipment slot constraints prevent invalid combinations (two-handed weapon blocks off-hand slot)
3. Visual equipment panel clearly shows all 10 slots with equipped/empty status
4. Drag-and-drop or hotkey equipment management for efficient gear swapping
5. Equipped items provide appropriate stat bonuses that update character stats immediately
6. Equipment removal returns items to inventory with proper slot availability checking

## Background / Rationale

The current equipment system supports 10 slots but needs full implementation of slot constraints, visual representation, and interaction patterns. This story establishes the foundation for the complete equipment economy by ensuring both players and monsters follow consistent equipment rules.

Key design goals:
- **Clear slot visualization:** Players must understand which slots are available/occupied
- **Weapon/off-hand constraints:** Two-handed weapons prevent off-hand use
- **Immediate stat feedback:** Equipment changes update stats in real-time
- **Consistent monster behavior:** Monsters use the same 10-slot system (foundation for Story 3.4)

### Two-Handed Weapon Constraint Logic

```typescript
interface EquipmentItem {
  // ... existing fields
  isTwoHanded?: boolean; // New field
}

function validateEquipmentChange(
  equipment: EquipmentSlots,
  newItem: EquipmentItem,
  targetSlot: keyof EquipmentSlots
): { valid: boolean; error?: string } {
  // If equipping two-handed weapon, check off-hand is empty
  if (targetSlot === 'weapon' && newItem.isTwoHanded && equipment.offHand !== null) {
    return { valid: false, error: 'Cannot equip two-handed weapon while using off-hand item' };
  }

  // If equipping off-hand, check weapon is not two-handed
  if (targetSlot === 'offHand' && equipment.weapon?.isTwoHanded) {
    return { valid: false, error: 'Cannot equip off-hand item with two-handed weapon' };
  }

  return { valid: true };
}
```

### Stat Recalculation Pattern

```typescript
function recalculateStats(hero: Hero): void {
  const equippedItems = getEquippedItems(hero.equipment);

  let totalAttackBonus = 0;
  let totalDefenseBonus = 0;

  for (const item of equippedItems) {
    totalAttackBonus += item.attackBonus;
    totalDefenseBonus += item.defenseBonus;
  }

  // Update hero's effective stats (store on hero object or calculate on-demand)
  hero.equipmentAttackBonus = totalAttackBonus;
  hero.equipmentDefenseBonus = totalDefenseBonus;
}
```
