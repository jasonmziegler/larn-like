# Story 2.9: Single Trophy Equipment Transfer

## Status
Done

## Story
**As a** game designer,
**I want** monsters to claim only one random equipment piece from a fallen hero,
**so that** equipment is scattered more widely across the dungeon in chests, creating exploration incentives and reducing the power spike of promoted monsters.

## Acceptance Criteria
1. When hero dies, the killing monster takes exactly ONE random equipped item (if any exist)
2. All remaining equipped items are distributed to newly spawned chests
3. Chests spawn at random valid floor positions on the current dungeon level
4. 1-4 chests are generated per death event to hold overflow equipment and teeth
5. Hero's carried teeth are distributed: 25% to current floor chests, 75% to next floor chests (if it exists)
6. If next floor doesn't exist, all teeth go to current floor chests
7. Chests display as `=` character in bright green color on the dungeon map
8. Chests can be opened by walking onto them (same as current behavior)

## Background / Rationale

The current implementation (Story 2.3) transfers ALL equipped items to the killing monster. This creates very powerful promoted monsters but reduces the roguelike element of discovering scattered loot.

This change:
- **Reduces monster power spike:** One trophy item instead of full loadout
- **Creates exploration incentives:** Scattered gear in chests encourages dungeon exploration
- **Maintains trophy narrative:** Monster still gets a trophy from its kill
- **Preserves teeth economy:** Teeth distribution (25%/75% split) already works correctly

## Dev Notes

### Current Equipment Transfer Logic

**DeathProcessor.ts:transferEquipment()** currently:
```typescript
for (const item of heroItems) {
  const slotKey = item.slot as keyof typeof killerMonster.equipment;
  if (killerMonster.equipment[slotKey] === null) {
    killerMonster.equipment[slotKey] = item;
    transferred.push(item);
  } else {
    overflow.push(item);
  }
}
```

**New logic should be:**
```typescript
if (heroItems.length === 0) return { transferred: [], overflow: [] };

// Pick one random item
const randomIndex = Math.floor(Math.random() * heroItems.length);
const selectedItem = heroItems[randomIndex];
const otherItems = heroItems.filter((_, i) => i !== randomIndex);

// Try to equip the single selected item
const slotKey = selectedItem.slot as keyof typeof killerMonster.equipment;
if (killerMonster.equipment[slotKey] === null) {
  killerMonster.equipment[slotKey] = selectedItem;
  return { transferred: [selectedItem], overflow: otherItems };
} else {
  // Monster already has item in that slot - everything goes to overflow
  return { transferred: [], overflow: heroItems };
}
```

### Chest Distribution Formula

Number of chests = `min(4, 1 + floor(overflowItems.length / 3) + (teethAmount > 0 ? 1 : 0))`

Examples:
- 0 items, 50 teeth → 2 chests (1 base + 1 for teeth)
- 2 items, 0 teeth → 1 chest (1 base)
- 5 items, 100 teeth → 3 chests (1 base + 1 for items + 1 for teeth)
- 10 items, 200 teeth → 4 chests (capped at 4)
