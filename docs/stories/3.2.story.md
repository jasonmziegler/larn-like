# Story 3.2: Town Hub and Merchant Interface

## Status
Draft

## Story
**As a** player,
**I want** to visit a town with merchants who accept teeth currency,
**so that** I can spend collected teeth to purchase better starting equipment before entering the dungeon.

## Acceptance Criteria
1. Town hub accessible from game start with clear navigation to/from dungeon entrance
2. Merchant NPC interface displays available equipment for purchase with teeth prices
3. Purchase system deducts teeth currency and adds equipment to player inventory
4. Merchant inventory includes upgrades to basic starting gear (better weapons, armor, etc.)
5. Town interface shows current teeth currency balance prominently
6. Equipment tooltips display stats and compare with currently equipped items

## Background / Rationale

The town hub serves as the economic foundation of the teeth currency system. Players accumulate teeth from dungeon deaths and can spend them on equipment upgrades, creating a meaningful progression loop across multiple runs.

Key design goals:
- **Teeth sink:** Provide valuable use for collected teeth currency
- **Progression path:** Offer equipment tiers beyond basic starting gear
- **Strategic decisions:** Force players to choose which upgrades to prioritize
- **Town/dungeon loop:** Clear spatial separation between safe commerce and dangerous exploration

### Purchase Transaction Flow

```typescript
function purchaseItem(hero: Hero, item: EquipmentItem, cost: number): { success: boolean; message: string } {
  if (hero.teethCurrency < cost) {
    return {
      success: false,
      message: `Not enough teeth. Need ${cost}, have ${hero.teethCurrency}`
    };
  }

  hero.teethCurrency -= cost;
  hero.inventory.push(item);

  return {
    success: true,
    message: `Purchased ${item.name} for ${cost} teeth`
  };
}
```

### Game Flow Update

**Current Flow:**
```
Title Screen → Character Creation → Dungeon Level 1 → Death → Title Screen
```

**New Flow:**
```
Title Screen → Character Creation → Town Hub
                                      ↓
                          [D] Enter Dungeon → Level 1 → Death → Town Hub
                          [M] Visit Merchant (buy gear)
                          [T] Return to Town (from dungeon)
```
