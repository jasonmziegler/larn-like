# Story 1.6: Basic Monster Reagent System

## Status
Draft

## Story
**As a** player,
**I want** to consume monster reagents to gain temporary stat bonuses,
**so that** I can experience character progression during my current dungeon run.

## Acceptance Criteria
1. Killed monsters drop reagents (rat tail, skeleton bone, etc.) as lootable items
2. Player can consume reagents through inventory interaction (hotkey or mouse)
3. Reagent consumption grants +0.1 stat bonus (Agility, Stamina, etc.) for current hero
4. Stat bonuses display clearly in character stats panel with updated values
5. Multiple reagent consumption properly stacks bonuses (+0.1, +0.2, +0.3, etc.)
6. Reagent effects last for entire hero lifespan and reset only on hero death

- **Skeleton Bone**: +0.1 Stamina bonus (from skeleton monsters)
- **Bat Wing**: +0.1 Dexterity bonus (from vampire bat monsters)

**Reagent Data Model:**
```typescript
interface MonsterReagent extends InventoryItem {
  type: 'reagent';
  monsterType: string;     // 'rat', 'skeleton', 'vampire_bat'
  statBonus: {
    stat: 'agility' | 'stamina' | 'dexterity';
    amount: 0.1;
  };
}
```

### Hero Stats System for Reagent Bonuses
[Source: architecture/data-models.md]
**Hero Stats Interface:**
```typescript
interface Hero {
  baseStats: HeroStats;      // Unchanging base stats
  currentStats: HeroStats;   // Modified by reagents and equipment
}

interface HeroStats {
  hp: number;
  maxHp: number;
  strength: number;         // Equipment bonuses
  dexterity: number;        // Reagent target: Bat Wing (+0.1)
  constitution: number;     // Equipment bonuses
  agility: number;          // Reagent target: Rat Tail (+0.1)
  stamina: number;          // Reagent target: Skeleton Bone (+0.1)
}
```

**Stat Modification Logic:**
- baseStats remain constant throughout hero lifetime
- currentStats = baseStats + equipment bonuses + reagent bonuses
- Reagent bonuses accumulate (+0.1, +0.2, +0.3) through consumption
- All bonuses reset to baseStats on hero death

### Database Support for Reagent Bonuses
[Source: architecture/database-schema.md]
**Heroes Table Stat Columns:**
```sql
-- Support for +0.1 reagent bonuses with DECIMAL(3,1)
current_strength DECIMAL(3,1) DEFAULT 10.0,
current_dexterity DECIMAL(3,1) DEFAULT 10.0,
current_constitution DECIMAL(3,1) DEFAULT 10.0,
current_agility DECIMAL(3,1) DEFAULT 10.0,
current_stamina DECIMAL(3,1) DEFAULT 10.0
```

**Reagent Bonus Precision:**
- DECIMAL(3,1) supports values like 10.0, 10.1, 10.2, 10.3, etc.
- Maximum theoretical bonus: 99.9 (allows extensive reagent consumption)
- Database automatically handles decimal precision for stat storage

```typescript
// Expected inventory integration for reagents
class Inventory {
  consumeReagent(reagent: MonsterReagent, hero: Hero): boolean {
    if (this.canConsume(reagent)) {
      this.applyStatBonus(reagent.statBonus, hero);
      this.removeItem(reagent);
      return true;
    }
    return false;
  }
}
```

### Reagent Consumption Mechanics
**Consumption Input Methods:**
- **Hotkeys**: Number keys (1-9) for inventory slot consumption
- **Mouse Interaction**: Click/right-click for reagent selection and consumption
- **Confirmation**: Optional confirmation dialog for valuable reagents

**Consumption Validation:**
- Check inventory slot contains reagent
- Validate reagent is consumable (not corrupted/invalid)
- Ensure hero is alive and can benefit from stat bonuses
- Prevent consumption during combat (optional restriction)

### Stat Bonus Stacking System
**Stacking Logic:**
```typescript
// Reagent consumption stacking example
class StatManager {
  applyReagentBonus(hero: Hero, stat: string, bonus: number) {
    hero.currentStats[stat] += bonus;
    this.updateDisplay(hero);
    this.persistStats(hero);
  }
}

// Example progression:
// Start: Dexterity 10.0
// After 1 Bat Wing: Dexterity 10.1
// After 2 Bat Wings: Dexterity 10.2
// After 3 Bat Wings: Dexterity 10.3
```

**Stacking Limitations:**
- No artificial stacking limits (bounded by inventory space)
- Stat bonuses persist until hero death
- Multiple reagent types can be consumed (mixed stat bonuses)

### Performance Considerations
**Reagent System Performance:**
- Efficient stat recalculation after reagent consumption
- Optimized inventory display for reagent identification
- Minimal database updates for stat persistence
- Real-time UI updates without gameplay lag

### Integration with Combat and Equipment
**Combat Integration:**
- Reagent-modified stats affect combat calculations
- Enhanced dexterity affects hit chance and defense
- Stamina bonuses affect HP or endurance mechanics
- Agility bonuses affect movement or dodge capabilities

**Equipment Synergy:**
- Reagent bonuses stack with equipment stat bonuses
- Total stats = base + equipment + reagents
- Equipment changes don't affect reagent bonuses
- Reagent effects independent of equipment swaps
