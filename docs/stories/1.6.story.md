# Story 1.6: Monster Reagent Consumption & Stat Bonuses

<!-- Context: Brownfield enhancement - local-only reagent consumption system, no backend persistence -->

## Status
Draft

## Story
**As a** player,
**I want** to consume monster reagents to gain stat bonuses during my dungeon run,
**so that** I can experience character progression through combat and feel rewarded for killing monsters.

## Acceptance Criteria
1. Player can view collected reagents via an inventory hotkey (I or Tab)
2. Player can consume a reagent from inventory to apply its stat bonus
3. Reagent consumption grants +0.1 stat bonus to the corresponding stat (Dexterity, Strength, Constitution)
4. Stat bonuses display in the stats panel with updated values showing decimal precision
5. Multiple reagent consumptions properly stack bonuses (+0.1, +0.2, +0.3, etc.)
6. Reagent effects persist for the hero's entire lifespan and reset on death
7. Inventory panel shows reagent names, quantities, and effect descriptions

## Dev Notes

### Existing Implementation (Brownfield Context)
**Hero.ts already provides:**
- `hero.currentStats` - mutable stats object (hp, maxHp, strength, dexterity, constitution)
- `hero.baseStats` - immutable base stats
- `hero.inventory` - array of EquipmentItem (can hold reagents)
- `createHero()` - creates fresh hero with base stats (effectively resets on new game)

**GameHUD.ts already provides:**
- `renderStatsPanel()` - displays STR, DEX, CON values
- `renderStatusBar()` - compact HP/ATK/DEF display
- Integration with CanvasRenderer

**From Story 1.5 (prerequisite):**
- Reagent items are added to `hero.inventory` on monster kill
- ReagentItem type with `statBonus: { stat, amount }` field

**What exists and must NOT be broken:**
- Hero stat calculations (getEffectiveAttack, getEffectiveDefense)
- Combat system using hero stats
- GameHUD rendering
- Game flow (title → naming → game → death → title)

### Reagent Types (from Story 1.5)
| Reagent | Source Monster | Stat | Bonus |
|---------|---------------|------|-------|
| Goblin Ear | Goblin | Dexterity | +0.1 |
| Orc Tooth | Orc | Strength | +0.1 |
| Troll Hide | Troll | Constitution | +0.1 |
| Dragon Scale | Dragon | All stats | +0.5 |

### Inventory UI Design
```
+---------- INVENTORY ----------+
| 1. Goblin Ear (x2)    +DEX   |
| 2. Orc Tooth (x1)     +STR   |
|                               |
| [1-9] Use  [ESC] Close       |
+-------------------------------+
```
- Overlay renders on top of game view
- Game input (movement) paused while inventory open
- Simple numbered list matching keyboard shortcuts

### Stat Display Format
```
STR: 10.2 (+0.2)    <- green highlighting on boosted stats
DEX: 10.1 (+0.1)
CON: 10.0            <- no bonus indicator when at base
```

### Testing Patterns
- **Environment**: `// @vitest-environment jsdom` at file top
- **Vitest**: Primary framework
- Test reagent consumption by creating hero, adding reagent to inventory, consuming, checking stats
- Test stacking by consuming multiple reagents of same type

### Performance Requirements
- Instant stat update on reagent consumption
- Inventory panel renders at 60fps
- No delay when opening/closing inventory
