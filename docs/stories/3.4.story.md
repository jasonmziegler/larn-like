# Story 3.4: Monster Equipment Slot Management

## Status
Draft

## Story
**As a** system,
**I want** monsters to follow the same 10-slot equipment constraints as players,
**so that** promoted monsters carrying trophy gear remain manageable and don't become overly complex.

## Acceptance Criteria
1. Monsters use identical 10-slot equipment system as players with same constraints
2. When monster equipment slots are full, overflow items automatically distribute to nearby dungeon chests
3. Monster equipment display in detail panels shows organized slot-based layout
4. Trophy equipment from defeated heroes properly fills monster slots according to item types
5. Monster stat bonuses from equipment calculate using same system as player equipment
6. Equipment slot management handles edge cases (multiple rings, weapon/off-hand combinations)

## Background / Rationale

Stories 2.3 and 2.9 established monster equipment transfer (single trophy system), but monsters need full 10-slot management to:
- **Prevent over-gearing:** Limit monster equipment to 10 slots (same as heroes)
- **Enable overflow:** Gracefully handle excess equipment via chest spawning
- **Maintain balance:** Ensure monster power scales predictably
- **Support inspection:** Allow players to see exactly what monsters are carrying

This story enforces equipment parity between heroes and monsters, ensuring the persistent world system remains balanced as monsters accumulate trophies across multiple hero deaths.

### Monster Effective Stat Calculation

```typescript
function getMonsterEffectiveAttack(monster: Monster): number {
  const baseAttack = monster.attack;
  const equippedItems = getEquippedItems(monster.equipment);
  const equipmentBonus = equippedItems.reduce((sum, item) => sum + item.attackBonus, 0);
  return baseAttack + equipmentBonus;
}

function getMonsterEffectiveDefense(monster: Monster): number {
  const baseDefense = monster.defense;
  const equippedItems = getEquippedItems(monster.equipment);
  const equipmentBonus = equippedItems.reduce((sum, item) => sum + item.defenseBonus, 0);
  return baseDefense + equipmentBonus;
}
```

### Equipment Overflow Handling

```typescript
// In transferEquipment() after Story 2.9 single-trophy logic:
const randomIndex = Math.floor(Math.random() * heroItems.length);
const selectedItem = heroItems[randomIndex];
const otherItems = heroItems.filter((_, i) => i !== randomIndex);

const slotKey = selectedItem.slot as keyof typeof killerMonster.equipment;

// NEW: Check if monster already has 10 items equipped
const monsterEquippedCount = getEquippedItems(killerMonster.equipment).length;
const slotOccupied = killerMonster.equipment[slotKey] !== null;

if (slotOccupied || monsterEquippedCount >= 10) {
  // Overflow: spawn chest for ALL items (including selected trophy)
  spawnOverflowChest(killerMonster.pos, heroItems, currentLevel);
  return { transferred: [], overflow: heroItems };
} else {
  // Equip the trophy
  killerMonster.equipment[slotKey] = selectedItem;
  return { transferred: [selectedItem], overflow: otherItems };
}
```

### Edge Cases to Handle

1. **Monster with 10 items receives new trophy:** All hero items → overflow chest
2. **Monster has ring1 filled, hero has 2 rings:** Random selection picks one ring
   - If selected ring slot is full → overflow
3. **Two-handed weapon on monster:** Blocks off-hand slot (same as hero)
4. **Promoted monster moves levels:** Equipment persists via MonsterRecord
