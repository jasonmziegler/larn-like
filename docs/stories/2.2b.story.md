# Story 2.2b: Fix Level Persistence on Staircase Traversal

## Status
Ready for Review

## Story
**As a** player exploring the dungeon,
**I want** dungeon levels to persist when I traverse stairs up and down,
**so that** I can navigate between levels without losing monster positions, items, or world state.

## Acceptance Criteria
1. When descending to a new level, that level is generated once and saved to IndexedDB
2. When ascending or descending to a previously visited level, the saved level is loaded (not regenerated)
3. Monster positions remain consistent when returning to a level
4. Items and teeth remain in the same locations when returning to a level
5. Killed monsters do not respawn when returning to a cleared level
6. Level persistence works correctly across multiple transitions (e.g., Level 1 → 2 → 1 → 2 → 3 → 2 → 1)

## Dev Notes

### Root Cause Analysis (from QA Investigation)

**Primary Issue: Async Race Condition**

The `persistLevel()` function is synchronous but calls an async operation without waiting:

```typescript
// Current (BROKEN):
function persistLevel(state: GameState, worldState: WorldState): void {
  const levelRecord = gameStateToLevelRecord(state);
  worldState.saveLevel(levelRecord).catch(console.error);  // Fire-and-forget!
}

// Then in transitionToLevel():
persistLevel(state, worldState);  // Doesn't wait
const newState = await initGame(...);  // Checks WorldState before save completes
```

**The Flow:**
1. `transitionToLevel()` calls `persistLevel()` (main.ts:271)
2. `persistLevel()` starts async `saveLevel()` but doesn't wait
3. Immediately calls `getOrGenerateLevel()` (via `initGame()`)
4. `getOrGenerateLevel()` checks `worldState.getLevel(depth)` in in-memory cache
5. The save hasn't updated in-memory state yet → returns `undefined`
6. Generates brand new level instead of loading saved one

**Secondary Issue: Monster Re-Population**

In `main.ts:152-186`, the logic repopulates monsters whenever `monsters.length === 0`:

```typescript
// If this is a freshly generated dungeon level (not town), populate with monsters
if (depth >= 1 && monsters.length === 0) {
  // Generate new monsters...
}
```

**Problem:** When you clear a level (kill all monsters) and return later, the saved level correctly has `monsters: []`, but then `initGame()` sees the empty array and spawns new monsters.

**WorldState.saveLevel() (`apps/web/src/world/WorldState.ts:162-171`):**
```typescript
async saveLevel(level: DungeonLevelRecord): Promise<void> {
  const existingIdx = this.state.levels.findIndex(l => l.depth === level.depth);
  if (existingIdx >= 0) {
    this.state.levels[existingIdx] = level;  // Update in-memory
  } else {
    this.state.levels.push(level);  // Add to in-memory
  }
  await this.store.saveLevel(level as unknown as Record<string, unknown>);
}
```
