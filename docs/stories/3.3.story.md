# Story 3.3: Dungeon Chest System for Equipment Overflow

## Status
Draft

## Story
**As a** player exploring dungeons,
**I want** to find equipment in dungeon chests,
**so that** I can discover additional gear beyond basic merchant purchases and monster drops.

## Acceptance Criteria
1. Dungeon chests appear as interactive ASCII symbols (chest icon) in dungeon rooms
2. Chest interaction reveals contained equipment with proper inventory management
3. Equipment overflow from monster inventory limits automatically populates nearby chests
4. Chest contents persist in world state and can be discovered by any future hero
5. Visual feedback distinguishes unopened chests from opened/empty chests
6. Chest spawning algorithm ensures reasonable distribution without overcrowding levels

## Background / Rationale

While Story 2.3 and 2.9 established basic chest functionality for death overflow (teeth and equipment from hero deaths), this story extends the chest system to support:
- **Random chest generation** on level creation (not just death events)
- **Persistent chest states** (opened vs unopened visual distinction)
- **Monster inventory overflow** (when monsters are over-equipped)
- **Equipment discovery loop** (exploration reward beyond combat)

This creates a more complete loot distribution system where equipment can be found through multiple paths: merchants (purchased), monsters (trophies), and chests (discovered).

### Random Chest Generation Algorithm

```typescript
function generateRandomChests(level: DungeonLevel): DungeonChestRecord[] {
  const chestCount = Math.floor(Math.random() * 3) + 1; // 1-3 chests
  const chests: DungeonChestRecord[] = [];
  const occupiedPositions: Position[] = [...level.monsters.map(m => m.pos)];

  for (let i = 0; i < chestCount; i++) {
    const pos = findEmptySpot(level.dungeon, occupiedPositions, width, height);
    occupiedPositions.push(pos);

    const itemCount = Math.floor(Math.random() * 3); // 0-2 items
    const items = generateChestLoot(itemCount);
    const teeth = Math.floor(Math.random() * 41) + 10; // 10-50 teeth

    chests.push({
      id: `chest_random_${level.depth}_${i}_${Date.now()}`,
      pos,
      items,
      teeth,
      isOpened: false,
      chestType: 'random',
    });
  }

  return chests;
}
```

### Chest Distribution Balance

**Target Distribution:**
- **Average per level:** 2 random chests + 0-1 death chests
- **Max chests per level:** 6-8 (prevents overcrowding)
- **Loot value:** Random chest ~100-150 teeth equivalent (items + teeth)
- **Death chest:** Variable (depends on hero death state)
