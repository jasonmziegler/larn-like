## Story
**As a** nostalgic roguelike player,
**I want** an authentic "Insert Coin" title screen experience,
**so that** I immediately recognize the retro gaming aesthetic and feel engaged with the classic arcade atmosphere.

## Acceptance Criteria
1. Title screen displays classic "INSERT COIN" prompt in authentic ASCII font styling
2. Credit counter shows available credits (starting with 3 free credits)
3. Pressing spacebar or designated key adds one credit with satisfying visual feedback
4. Enter key starts new game when credits available, reducing credit count by 1
5. Screen provides visual feedback when no credits available and player attempts to start
6. Title includes game name and basic instructions for credit system

class TitleScreen {
  private credits: number = 3; // Default starting credits

  loadCredits() {
    const saved = localStorage.getItem('credits');
    this.credits = saved ? parseInt(saved) : 3;
  }

  saveCredits() {
    localStorage.setItem('credits', this.credits.toString());
  }
}

### Review Date: 2026-01-28

### Reviewed By: Quinn (Test Architect)

### Code Quality Assessment

Solid implementation. The TitleScreen component has clean single-responsibility architecture with well-separated concerns (state, input, rendering, lifecycle). The callback pattern for game start transition is appropriate. Proper lifecycle management with show/hide and input binding cleanup prevents memory leaks.

The main.ts integration is clean - game input handler is properly removed before showing the title screen, preventing input conflicts.

### Refactoring Performed

- **File**: `apps/web/src/ui/TitleScreen.ts`
  - **Change**: Replaced 6 hardcoded `80` values with `VIEWPORT_WIDTH` constant (from `GAME_CONSTANTS.VIEWPORT_WIDTH`), and `24` with `VIEWPORT_HEIGHT`
  - **Why**: Magic numbers reduce maintainability; if viewport dimensions change, all centering calculations would silently break
  - **How**: Added `const VIEWPORT_WIDTH = GAME_CONSTANTS.VIEWPORT_WIDTH` and `const VIEWPORT_HEIGHT = GAME_CONSTANTS.VIEWPORT_HEIGHT` at module level, used throughout render methods

- **File**: `apps/web/tests/unit/ui/TitleScreen.test.ts`
  - **Change**: Added 3 new tests for visual feedback (flash state rendering)
  - **Why**: AC3 requires "satisfying visual feedback" for credit addition and AC5 requires "visual feedback when no credits" - these were untested
  - **How**: Added tests verifying credit counter renders in correct colors during credit flash (bright green), error flash (red), and zero-credits state (dim)
